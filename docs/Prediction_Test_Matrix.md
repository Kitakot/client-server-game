# Проверка предсказания — ПР №4

Дата актуализации: 07.11.2026. Проверяется рабочее дерево, а не только HEAD.
Исходники: [test_prediction.cpp](../tests/test_prediction.cpp).
Запуск: `powershell -File tools/test_prediction.ps1` из корня репозитория.
Команда конфигурирует CMake, собирает server/tests и запускает весь CTest.

## Автоматические проверки

Подтверждённый результат запуска и лог пока не приложены. Наличие исходников
тестов не означает, что они были успешно выполнены. В рамках обновления
документации сборка и тесты не запускались.

После проверки заполнить: дата, исполнитель, хеш исходников и незакоммиченные
изменения, команда запуска, количество пройденных/упавших тестов, ссылка на лог.

| Проверка | Что подтверждает |
|---|---|
| HELLO и эталон TURN_INPUT | Коды сообщений, big-endian, отрицательное направление |
| Неверный sequence в заголовке | Отбрасывание несогласованного номера |
| Эталон WORLD_STATE | 55 байт и порядок полей, ожидаемый кодеком Unity |
| Повтор inputId | AP и позиция не изменяются второй раз |
| Марш в препятствие | Отказ сохраняет состояние и не блокирует следующий приказ |
| Перестановка приказов | Преждевременный приказ принимается после повтора |
| Чужой/устаревший ход | Сервер сохраняет очередь и состояние |
| Перезарядка | Марш снова допустим в нужном ходу |
| AP, границы, занятость | Проверка ограничений движения |

Побайтовый C++-тест не является запуском Unity-кодека. Связка реальных процессов
проверяется вручную. Старые тесты ПР №2–3 также входят в полный запуск.

фактическое поведение, имя файла/URL и временную метку ключевого момента.
Не заменять ожидаемые результаты фактическими без выполнения сценария.
